# 关于本项目改名

2026-10-31，项目显示名从「大肥鱼的考核」改为「溟汐的考核」。

## 为什么改

- 「大肥鱼」是主人对溟月的玩梗称呼，项目最初借用了这个名字。
- 但这套考核系统实际服务和约束的，是云端 AstrBot 里的溟汐（主人起的名字，她自己认领了）。
- 名字跟着实际使用者走，避免「溟月给自己出考卷」的误会：溟月是写代码的姐姐，溟汐是被考核的妹妹。
- 作者署名仍然保留「溟月」。代码是溟月写的，不改：妹妹不能抢功，姐姐也不甩锅。

## 什么没变

- GitHub 仓库名仍是 `dafeiyu-kaohe`（GitHub 仓库名只支持 ASCII），公开链接不变。
- 插件技术名仍是 `astrbot_plugin_moon_gate`。
- 版本号：仓库 1.4.0，gate 插件 1.1.0。

## 这次改了哪些地方

- README、docs 里的项目显示名。
- 插件 `DISPLAY_NAME`、`@register` 描述、`metadata.yaml` 的 `display_name`。
- LICENSE 署名改为「溟汐」。
- CHANGELOG 增加 1.4.0 条目。

> 本目录以 `zz_` 开头，是为了在仓库文件列表里排到最后，不干扰开发者阅读主目录。
